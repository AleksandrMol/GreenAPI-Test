# Telegram Web UI на GREEN-API

Минимальный клиент для отправки и получения текстовых сообщений в Telegram через GREEN-API.

## Требования
- Node.js 20+
- Активированный Telegram-инстанс GREEN-API
- В настройках инстанса должен быть включён приём входящих уведомлений, а `webhookUrl` должен быть пустым для режима HTTP API polling.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite. Нажмите на шестерёнку, укажите `apiUrl`, `idInstance` и `apiTokenInstance`, затем сохраните настройки. Для вашего инстанса API URL: `https://4100.api.green-api.com`.

Введите Telegram Chat ID в поле слева. Для личного диалога укажите числовой идентификатор, который поддерживает GREEN-API. После открытия чата можно отправлять текстовые сообщения; входящие текстовые уведомления отображаются в активном чате.

## Сборка

```bash
npm run build
npm run preview
```

## Ограничения первой версии
- История сообщений хранится только в памяти вкладки и очищается при перезагрузке или переключении чата.
- Отображаются только текстовые входящие уведомления.
- Для получения сообщений используется HTTP API polling (`ReceiveNotification` → обработка → `DeleteNotification`). Необработанные типы уведомлений подтверждаются и пропускаются.
- Учётные данные не сохраняются в `localStorage`; при обновлении страницы их нужно ввести заново.

## Безопасность
Это учебный клиент без собственного backend. API-токен используется непосредственно браузером и доступен пользователю в DevTools. Для публичного промышленного приложения следует добавить серверный proxy/backend и управление секретами на сервере.

## Структура проекта

```text
src/
├── api/                 # HTTP-клиент GREEN-API
├── components/          # UI-компоненты приложения
│   ├── ChatSidebar.tsx  # Список/выбор текущего чата и статус подключения
│   ├── Conversation.tsx # Заголовок диалога, сообщения и поле ввода
│   ├── ErrorToast.tsx   # Отображение ошибок
│   └── SettingsModal.tsx# Форма конфигурации GREEN-API
├── hooks/               # React hooks для побочных эффектов
├── types/               # Общие типы данных
├── App.tsx              # Композиция компонентов и состояние приложения
├── main.tsx             # Точка входа React
└── styles.css           # Глобальные стили
```

Компоненты отвечают за отображение и пользовательские события. В `App` сосредоточено состояние текущего чата и отправки сообщений, `api` инкапсулирует HTTP-запросы, а `useNotifications` управляет циклом получения и подтверждения уведомлений.
